## 🚀 Tech Stack

| Technology | Use |
|---|---|
| [Astro](https://astro.build/) | Static web framework (SSG) |
| [TypeScript](https://www.typescriptlang.org/) | Static typing across the project |
| [Sharp](https://sharp.pixelplumbing.com/) | Pixel art asset generation pipeline |
| CSS Custom Properties | Retro theming without external dependencies |

## 🛠️ Local Setup

```bash
# Clone the repository
git clone https://github.com/bryanalvaradowd/airline-fleet.git
cd airline-fleet

# Install dependencies (requires Node.js >= 18)
npm install

# Start development server
npm run dev
# → http://localhost:4321

# Production build
npm run build

# Preview build
npm run preview
```
